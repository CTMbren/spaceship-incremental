# Last Tug: Idle Salvage

A mobile-first incremental spaceship game: tractor in asteroids, crush them, smelt, and grow a modular ship tile by tile.

- Play: https://ctmbren.github.io/spaceship-incremental/ (after enabling Pages)
- Dev: `npm install && npm run dev`
- Test: `npm test` · Build: `npm run build`
- Docs: `docs/`
